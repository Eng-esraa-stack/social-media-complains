# لوحة مؤشرات ومتابعة شكاوى المواطنين — محافظة جنوب سيناء

نسخة ويب من ملف الإكسل `متابعة_شكاوى_المواطنين_ولوحة_المؤشرات.xlsx` بنفس شكل الشيتات:
**لوحة المؤشرات** (المؤشرات + 6 رسوم + الجداول الداعمة) · **سجل الشكاوى** (مع بحث وفلاتر وترتيب) · **القوائم** · **ملاحظات**.

## العرض على GitHub Pages
1. ارفع كل محتويات هذا المجلد إلى مستودع (Repository) على GitHub.
2. من **Settings → Pages**: اختر `Deploy from a branch` ثم الفرع `main` والمجلد `/ (root)` واضغط Save.
3. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

## تحديث البيانات
بعد تعديل ملف الإكسل (ضع النسخة الجديدة في نفس المجلد بنفس الاسم):
```
pip install openpyxl
python scripts/build_data.py
```
ثم ارفع التغييرات (`data.js` + ملف الإكسل). المؤشرات وعمر الشكوى وتاريخ «آخر تحديث» تُحسب تلقائياً وقت فتح الصفحة.

## الملفات
- `index.html` / `style.css` / `app.js`: واجهة العرض
- `data.js`: البيانات المستخرجة من الإكسل
- `scripts/build_data.py`: يحوّل الإكسل إلى `data.js`
- `.nojekyll`: يمنع معالجة Jekyll
